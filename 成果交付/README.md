## 数据文件为什么是 .js 而不是 .json

微信小程序的 `require` 只解析 `.js` 模块。写 `require('../data/recipes.json')` 会直接报错：

```
Error: module 'data/recipes.json.js' is not defined, require args is '../data/recipes.json'
```

`.json` 在小程序里只能作配置文件（`app.json`、页面 json、`sitemap.json`）。

所以 `data/` 下三个文件是 js 模块，**字段结构一个都没变**，只是外面包了一层：

```js
module.exports = <原有的 JSON 数组或对象>;
```

A 的流水线只要把 `JSON.stringify` 的结果套上这一行即可。这件事需要同步给 A 和 B，否则 A 直接覆盖成 `.json` 文件时数据不会生效。
